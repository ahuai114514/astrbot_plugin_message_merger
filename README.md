# astrbot_plugin_message_merger

该项目由 Codex 编写。

这是一个 AstrBot 消息合并插件，采用“乐观合并”策略：第一条消息立即进入原有 LLM 流程，不额外等待；如果同一用户在旧回复发送前继续发消息，插件会抑制旧结果，并让最新请求携带已经合并的消息重新生成。

## 行为

- 按 `统一消息来源 + 群聊范围 + 用户 ID` 隔离缓存，不会合并群里不同用户的消息。
- 无法取得可靠用户 ID 时不执行合并，避免串消息。
- 指令前缀（默认 `/`、`!`）和图片、文件、语音、视频、转发等非纯文本消息不参与合并。
- 不自行调用模型，继续使用 AstrBot 当前会话的模型、人格、上下文和工具。

## 重要边界

插件只能抑制尚未发送的旧回复。如果旧回复已经发到平台，平台通常无法可靠撤回；此时后续消息会作为新的请求处理。乐观重试可能产生额外 token 消耗，这是不增加首条等待时间的代价。

## 配置

- `enabled`：总开关。
- `max_messages`：一次最多缓存的消息条数，默认 8；设为 `0` 时不限制条数。
- `max_chars`：一次最多合并的字符数，默认 4000；设为 `0` 时不限制字符数。
- `ignore_prefixes`：不参与合并的指令前缀，默认 `/` 和 `!`。

## 安装

将本目录复制到 AstrBot 的插件目录并在管理面板加载，按需调整配置后重载插件。
